## 世界现在正在发生什么

这些是观测、预测或模型数据的窗口，并非无遗漏的全球直播。

- ✈️ [飞机正在飞往哪里 · Flightradar24](https://www.flightradar24.com/) — 航班位置与轨迹；覆盖、延迟和部分功能因数据源与套餐而异。
- 🚢 [商船怎样连接大陆 · MarineTraffic](https://www.marinetraffic.com/) — AIS 船舶地图；部分数据需登录或付费，注意位置更新时间。
- 🛰️ [今晚头顶有什么 · Heavens-Above](https://www.heavens-above.com/) — 轨道预测与可见过境；先设置地点，并非实时观测。
- 🌋 [地球刚刚动了哪里 · USGS](https://earthquake.usgs.gov/earthquakes/map/) — 近实时地震信息；震级会修订，筛选门槛影响显示。
- 🌩️ [雷暴正在何处闪烁 · LightningMaps](https://www.lightningmaps.org/) — 社区雷电观测；覆盖不完整，不替代官方预警。
- 🌊 [风与洋流如何流动 · earth.nullschool](https://earth.nullschool.net/) — 模式与观测数据可视化；查看图层时间，不是全球现场直播。
- 🌐 [跨洋网络的实体路线 · Submarine Cable Map](https://www.submarinecablemap.com/) — 海底光缆地图；展示线路，不展示实时消息流。

## 我们如何做内容

一个问题 → 一句话解释 → 三件值得知道的事 → 一个小行动 → 来源 → 下一个问题。

正文为原创短读，链接用于继续阅读。涉及地区、产品和政策的条件要写明；不复制其他指南，不使用推广链接。暂不接受只有标题、没有解释的批量内容。
