# 001 · 为什么输入一个网址就能打开网站？

> 网址是入口，DNS 帮你找到地址，网络协议负责把内容送回来。

你输入 example.com，浏览器先寻找对应的网络地址。它再与服务器建立连接，请求页面，最后把 HTML、样式和图片组合成你看到的网站。一次看似简单的点击，背后有好几次协作。

## 三件值得知道的事

- 域名方便人记忆，IP 地址用于网络寻址；DNS 是两者之间的查询系统。
- HTTPS 使用 TLS 保护传输；网页仍可能来自缓存或 CDN，不一定来自同一台机器。
- 页面常由多个请求组成。页面打开了而图片没出现，可能只是其中一个请求失败。

## 试着做一件事

观察浏览器开发者工具的 Network 面板：刷新一次页面，看看请求数量。
