# 013 · 手机丢了，你还能登录自己的账号吗？

> 你需要的不是另一串密码，而是一条不依赖那部手机的恢复路径。

设想一下：手机找不到了。你想登录邮箱，却要点手机上的确认通知；想登录网盘找恢复码，网盘又要短信验证码。你记得密码，但所有备用入口都挤在同一台设备里。

安全与可恢复性需要一起设计。开启双重验证之后，下一件事就是确认：失去其中一个验证工具时，自己还有什么办法。

## 三件值得知道的事

- **密码不是完整的登录能力。** 密码加短信、验证器或设备确认，可能需要你同时持有第二个因素。忘记密码与丢失验证设备，是两种不同的恢复问题。
- **备用路径必须真的独立。** 放在丢失手机里的恢复码，或只能用该手机登录的云盘，在这种情况下都帮不上忙。平台支持时，可准备恢复码、备用安全密钥或另一台已配置的设备，并安全存放。
- **主邮箱也需要恢复方案。** 很多服务用邮箱找回账号；若邮箱依赖手机，手机相关账号又依赖邮箱，容易形成循环。不同平台恢复流程不同，备用凭据也不是万能保证。

## 看清自己的恢复链

| 入口 | 手机不在时，检查什么 |
| --- | --- |
| 主邮箱 | 有没有可用的备用验证方式？ |
| 密码管理器 | 另一台设备能否访问？解锁它需要什么？ |
| 手机号码 | 如何联系运营商挂失和补卡？ |
| 重要云盘 | 恢复码是否只能从这个云盘里取出？ |

不要把真实密码、恢复码或完整身份资料写进这张表，更不要发给别人。记录“在哪里、用什么方式”，秘密本身应另行保护。

## 试着做一件事

今天只选一个关键账号，查看官方恢复说明，确认已有备用方式仍可用。若支持恢复码，将它保存到安全且独立的位置。不要为测试而删除验证器、退出所有设备或关闭现有验证方式。
